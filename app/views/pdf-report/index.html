Generate PDF site report

Upload a baseline and a post-intervention GeoPackage to see what the site summary looks like as a printable, downloadable PDF — site maps over an Ordnance Survey basemap, then one card per habitat parcel showing every attribute the file records.

Nothing is calculated. Every number on the report is read from the files you upload or measured from their geometry, so there are no biodiversity unit figures on it. This tool is about the design and the layout of the data.

Files

A BNG-template .gpkg in British National Grid (EPSG:27700). Required. Maximum {{ maxUploadMb }} MB.
Optional. Without it the report is baseline-only: one site map, and the parcel cards describe the baseline habitats.

Accessibility

The report is a tagged PDF targeting PDF/UA-1: every map is a figure with alternative text, decoration is marked so screen readers skip it, and every value shown on a map is also given as text in the same card. Passing an automated checker is necessary but not sufficient — whether the alternative text is useful is a human judgement, so NVDA and PAC passes still apply.
